Academic Project Spotlight: Time Series Forecast Model of Bitcoin Prices
Predictive Analytics for Financial Decision-Making

As part of my graduate coursework, I completed a comprehensive time series forecasting project analyzing Bitcoin daily closing prices from 2014–2023 using multiple forecasting techniques.

🔍 Models Evaluated:
• Naïve Model
• Seasonal Naïve Model
• ETS (Error-Trend-Seasonality)
• TSLM
• ARIMA

📈 Key Highlights:
• Performed data cleaning, transformation, and stationarity testing
• Applied log transformation and differencing for time series modeling
• Evaluated models using RMSE, MAE, MAPE, and MASE
• ETS achieved the best forecasting accuracy
• ARIMA provided strong interpretability for autocorrelation and temporal dependencies
• Generated 30-day and 365-day Bitcoin price forecasts

This project strengthened my understanding of predictive analytics, time series forecasting, statistical modeling, and data-driven financial analysis.

Grateful for the opportunity to apply analytics concepts to real-world financial data and gain deeper insights into cryptocurrency market behavior.
